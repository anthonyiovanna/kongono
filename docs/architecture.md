# Kongono v1.17 Architecture & Deployment

## 11 Cohesive, Zero-Legacy Packages

Kongono keeps clean package boundaries across 11 focused PHP 8.5.13+ namespaces delivered in one unified package (`kongono/framework`) with **zero Symfony packages**, **zero third-party runtime libraries** beyond the 7 PSR interface packages, **100% `declare(strict_types=1)`**, and **zero mutable static properties**:

1. **`kongono/core`** — Persistent `Kernel` + `OperationScope`, PSR-11 `Container` with `resetScope()`, pure-DI `ClockInterface`/`SystemClock`/`FrozenClock`, Fiber `Async`, `Config`, `EnvLoader`, PSR-3 secret-scrubbing `Logger`, `MemoryCache`/`FileCache`/pure-PHP `RedisClient` + `RedisCache`/`CacheFactory`, `FeatureManager`, multi-channel `NotificationDispatcher`, `Retry`/`CircuitBreaker`, `Metrics`/`Tracer`, `HealthCheck`, `I18n\Translator`, nondisclosing `Diagnostics`/`SecretScrubber`, PSR-14 `EventDispatcher`, and live `ApplicationGraph`.
2. **`kongono/http`** — Native PSR-7/15 `Request`/`Response`/`Cookie`/`UploadedFile`, **Kongono Live 2.5** (`LiveMiddleware`, keyed morphing, zero-`eval()` strict-CSP AST signals, `kgn-oob`, `k-persist`, `kgn-sortable`), **Kongono Bridge** (`BridgeMiddleware`, `Response::page()`, `Response::adaptive()`), `Session` + PRG flash, `StaticFilesMiddleware`, `CompressionMiddleware`, `HttpCacheMiddleware`/`#[CacheControl]`, `IdempotencyMiddleware`/`#[Idempotent]`, `#[Feature]`, `#[Prefix]`, `#[Middleware]`, `EventBus`/`RedisEventBus` SSE pub/sub, `OpenApiGenerator`, `/docs` `ApiDocsRenderer`, `/_kongono` `DevDashboardMiddleware`, `/_ops` `OpsDashboardMiddleware`, `DevErrorRenderer`, `TestClient`/`TestResponse`/`TestUpload`, `O(1)` static + chunked PCRE2 AOT `Router`, and zero-reflection `App`.
3. **`kongono/view`** — Compiled `.kgn.html` OPcache closure templates (`warmCache()`, `autoReload: false`) with context-aware XSS auto-escaping, `@liveScript`, `@bridgeScript`, `@island`, `@safeHtml`, `@old`/`@error`, `@vite(...)`, layouts, loops, `@t(...)` i18n, `@json`, and nested `<x-component>` slots.
4. **`kongono/validation`** — Attribute-driven PHP 8.5 typed DTO validation (`#[Required]`, `#[Min]`, `#[Max]`, `#[Between]`, `#[Email]`, `#[Url]`, `#[Uuid]`, `#[Date]`, `#[Ip]`, `#[In]`, `#[NotIn]`, `#[Regex]`, `#[Confirmed]`, `#[RequiredIf]`, `#[ArrayOf]`), `RuleInterface`, `ValidatableDtoInterface`, native `BackedEnum` coercion, and recursive nested DTO validation.
5. **`kongono/database`** — Parameterized `QueryBuilder` (soft deletes, fail-closed `forTenant()` + PostgreSQL `RowLevelSecurity`, `JOIN`, `whereGroup()`, `upsert()`, `GROUP BY`, `HAVING`, `RETURNING`, `paginate()`, `getAs()`, `insertMany()`), zero-N+1 `BatchLoader` (`hasMany`/`belongsTo`), `QueryGuard`, typed `Factory`, `Schema`/`Blueprint` (`table`/`rename`/`softDeletes`/`foreignId`), `PdoConnection` (auto-reconnect, statement cache, nested `SAVEPOINT` transactions, `onQuery()`), `DatabaseTestHelper`, `Migrator` (`--pretend`, `rollback`, `lint`, `fresh`), `PostgresFullTextSearch`/`MemorySearchEngine`, `Repository`, and `SeederInterface`.
6. **`kongono/security`** — `SessionAuth` + `#[Authenticated]`, revocable SHA-256 `PersonalAccessToken` (`Memory`/`Cache`/`Pdo` stores), `PasswordResetBroker`, `EmailVerifier`, `LoginThrottler`, `RememberMeManager`, WebAuthn `PasskeyVerifier`, `MagicLinkAuth`, `PkceOAuthClient`, `AiThreatShieldMiddleware`, `Principal` (`Human`/`Service`/`Agent`/`System`), fail-closed `Gate` (policies + `before()`), `#[Can]` + `AuthorizeMiddleware`, `HtmlSanitizer`, Argon2id `PasswordHasher`, HKDF `Encryptor` v2 (`XChaCha20-Poly1305` + key rotation), RFC 6238 `Totp` 2FA/MFA, HMAC `TokenSigner` & `SignedUrl`, SSRF-hardened DNS-pinning `SafeHttpClient` + `SafeHttpClient::fake()`, signed Webhooks (`WebhookSigner`, `WebhookDispatcher`, `#[VerifyWebhook]`), and CSRF/CORS/Bearer/RateLimit/SecurityHeaders middleware.
7. **`kongono/storage`** — Streaming (`putStream`/`getStream`), `copy`/`move`, contained atomic SHA-256 versioned `LocalStorage`, pure-PHP AWS SigV4 `S3Storage` (S3/R2/MinIO, paginated `ListObjectsV2`, native server-side copy, presigned URLs), `MemoryStorage`, `StorageDisks`, `StorageFactory`, magic-byte `UploadedFileStore`, and `SignedLocalUrl`.
8. **`kongono/jobs`** — Background `Queue`, persistent/daemon `Worker` (multi-queue priority draining, `JobMiddlewareInterface`, preserving `JobOutcome::Uncertain`), dead-letter `listFailed`/`retryFailed`/`flushFailed`, atomic `uniqueKey` dedup, parallel `JobBatch` + `BatchDispatcher`, durable `Workflow` (`step`/`sleep`/`waitForEvent`/`signal`), `PostgresQueueDriver` (`FOR UPDATE SKIP LOCKED` + fencing tokens), pure-PHP Lua-atomic `RedisQueueDriver`, `MemoryQueueDriver`, and cron `Scheduler`.
9. **`kongono/mail`** — Zero-dependency transactional email (`SmtpTransport` STARTTLS, `ResendTransport`, `LogTransport`, `MemoryTransport`, `MailNotificationChannel`, and compiled `.kgn.html` email views).
10. **`kongono/ai`** — Multi-provider `AiClient` (OpenAI, Anthropic Claude, Google Gemini, local Ollama) with live streaming, `PromptGuard`/`UntrustedInput`, `EvalRunner`, vector embeddings (`MemoryVectorStore` + `PgVectorStore` HNSW/GIN), `HybridSearch` (Reciprocal Rank Fusion), 5-line RAG `KnowledgeBase`, `structured()` DTO extraction, capability-governed `AgentPrincipal`/`RequiresApproval`/`AgentRunner`, and native JSON-RPC 2.0 `McpServer`.
11. **`kongono/cli`** — Unified `kongo` CLI and built-in **Oshie**, **Chie**, and **Hantei** AI companions plus the 12-tool `KongonoMcpFactory`.

## Persistent-Runtime First Lifecycle

Kongono never stores per-request state in static properties, `$_SESSION`, or global facades. Superglobals are read exclusively in `Request::fromGlobals()`. Every HTTP request and background job executes inside `Kernel::runOperation()` (running deferred cleanups in LIFO order) and resets scoped DI container instances (`Container::resetScope()`) on exit.

See [Production Deployment & Scaling Guide](production-deployment.md) for FrankenPHP workers, `kongo optimize`, PostgreSQL/`pgvector`, `/_ops`, and Redis scaling.
