# Kongono Extension Inspection

This Experimental package inspects one explicit canonical extension-declaration artifact and one explicit generated extension-wiring file. Both inputs are validated structurally as inert bytes, their declaration-set identities must match, and the result contains only bounded aggregate evidence and fixed limitation tokens.

Generated PHP is never loaded, required, reflected, or executed. Structural validity does not establish currentness, authority, host state, execution, trust, health, installation, approval, or production readiness. Trusted in-process PHP remains not sandboxed.

Role-addressed Chie, Hantei, and Oshie views carry the same Safe aggregate evidence. The roles grant no authority and create no dependency on those packages. Independent verification compares seven fixed evidence groups and emits only fixed ordered failure tokens.

See [ADR 0137](../../docs/adr/0137-visibility-safe-extension-inspection-and-developer-intelligence-evidence.md) and the [architecture guide](../../docs/architecture/extension-inspection-and-developer-intelligence.md).
