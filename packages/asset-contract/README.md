# Kongono Asset Contract

`kongono/asset-contract` is the optional Experimental Phase 19B package for
bounded, immutable, language-neutral asset declarations and delivery metadata.

It defines logical and content identities, closed asset and content-type
vocabularies, dependency and entry-point relations, integrity evidence, and
inert preload hints. An empty declaration set is the first-class no-asset
contract.

The package performs no filesystem access, discovery, parsing, graph traversal,
building, bundling, publication, URL construction, HTTP work, view integration,
runtime resolution, or external effect. Its values and metadata grant no
authority.
