# Kongono Asset Inspection

`kongono/asset-inspection` is the optional Experimental Phase 19G upper
evidence leaf. It accepts exactly one supplied `CurrentAssetApplicationBuild`,
reconstructs its resolution artifact from public immutable evidence, and emits
only deterministic Safe aggregates and Protected SHA-256 bindings.

It reads no asset files or output bytes and performs no discovery, build,
resolution, serving, role execution, recording, export, repair, or production
observation. Supplied-current structural evidence does not establish live
filesystem currentness, deployment, browser behavior, security, accessibility,
performance, Graph ownership, certification, or production readiness.
