# Kongono View Inspection

`kongono/view-inspection` is the optional Experimental Phase 18G upper evidence
leaf. It accepts one explicit already exact-current `ViewApplicationProfile`,
structurally revalidates its in-memory compiled artifact, and independently
checks the profile and artifact bindings without loading generated PHP.

## Evidence boundary

The canonical `kongono.view-inspection` version 1 value contains only fixed
tokens, bounded Safe aggregates, and Protected lowercase SHA-256 bindings.
Caller-supplied exact-current evidence is not live filesystem currentness.
Paths, templates, source or generated bytes, context data, rendered output,
HTTP values, failures, and arbitrary caller content are never returned.

Graph projection copies only Safe aggregate counts and fixed vocabulary from an
explicit matching-role intelligence view. Its relationship remains
`not-established`. Observation and Security Audit projectors construct neutral
in-memory values marked `constructed-not-recorded`; they record, export, retain,
or certify nothing. Chie, Hantei, and Oshie select explain, verify, and teach
purposes without executing those roles.

Independent verification reconstructs the exact permitted intelligence fields
without calling the deriver or repairing a candidate. The package is
synchronous, bounded, deterministic, offline, read-only, and stateless. It
performs no rendering, generated-code execution, source or artifact I/O,
production observation, role execution, recording, export, or certification.

Consumer-facing types are Experimental. Canonicalization and diagnostics are
Internal. This package supplies no Graph relationship, authority, deployment,
runtime-currentness, Stable/1.0, or production-readiness claim.
