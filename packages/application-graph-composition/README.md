# Kongono Application Graph Composition

Experimental `kongono/application-graph-composition` is the supported pure
in-memory frontend from one exact Composition version-2 artifact to Phase 11C
IR records and an authoritative structural Graph. It validates the artifact,
derives framed domain-separated identities and artifact-bound provenance,
projects the closed Composition vocabulary, and delegates one complete record
set to the existing Graph builder.

Use it only with an already-built `CompositionArtifact`. It performs no source
reading, Reflection, scanning, serialization, publication, loading, currentness
check, query, command, registry, consumer integration, or operational action.
Returned values are fresh, detached, canonical, and non-authorizing. Phase 11E
artifact work is not implemented.
