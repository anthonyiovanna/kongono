Kongono v1.20 Documentation

Everything you need to build, test, secure, and scale modern PHP 8.5.13+ applications with zero Symfony runtime dependencies and zero mutable global state.

1. Quick Start

Requirements: PHP 8.5.13+ (ext-curl, ext-dom, ext-json, ext-mbstring, ext-pdo, ext-sodium) and Composer 2.x.

Create a New Project (Recommended)

composer create-project kongono/app my-app
cd my-app
composer dev

The installer automatically copies .env.example to .env and generates a 256-bit APP_KEY. Open:

  • App Home: http://127.0.0.1:8000/
  • Kongono Dev Studio: http://127.0.0.1:8000/_kongono
  • Operations Dashboard (when enabled): http://127.0.0.1:8000/_ops
  • Interactive OpenAPI 3.1 Explorer: http://127.0.0.1:8000/docs
  • Readiness Health Check: http://127.0.0.1:8000/health

Install into an Existing Project

composer require kongono/framework
php vendor/bin/kongo doctor

3. Routing & PHP 8.5 Attributes

Register controllers with $app->controller(PostController::class) or fluent route closures via $app->routes(fn(Router $r) => ...). Parameter dispatch plans are compiled once per controller method (zero per-request reflection in persistent workers), with automatic DI for Request, Session, Principal, typed route params, Container services, and validated DTOs.

#[Prefix('/api/posts')]
final readonly class PostController
{
    #[Get('/', name: 'posts.index')]
    #[CacheControl(maxAge: 60, public: true, staleWhileRevalidate: 30)]
    public function index(): Response { ... }

    #[Get('/{id:\d+}', name: 'posts.show')]
    public function show(int $id): Response { ... }

    #[Post('/', name: 'posts.create')]
    #[Middleware(BearerAuthMiddleware::class)]
    #[Authenticated]
    #[Can('posts.write')]
    #[Idempotent(ttlSeconds: 3600)]
    public function store(CreatePostInput $input, Principal $principal): Response { ... }
}
AOT Compiled Router: Static routes dispatch in O(1) hash lookup; dynamic routes compile into chunked PCRE2 regexes via php vendor/bin/kongo optimize (var/cache/routes.compiled.php).

4. Compiled .kgn.html Views & Vite

Templates live in views/ and compile once into OPcache-friendly static PHP closures. All {{ $expr }} and @t(...) outputs are contextually HTML-escaped against XSS; use @safeHtml($richHtml) to sanitize user-authored markup via Kongono's built-in HTML5 HtmlSanitizer.

@extends('layouts/app')
@section('title', 'Dashboard')

@section('content')
  <h1>@t('dashboard.welcome', ['name' => $user->name])</h1>

  @unless ($archived)
    <x-card :title="$project->name">
      @forelse ($tasks as $task)
        <p>{{ $task->title }}</p>
      @empty
        <p>All caught up!</p>
      @endforelse
    </x-card>
  @endunless

  <script>window.__DATA__ = @json($payload);</script>
@endsection

In production persistent workers (FrankenPHP / RoadRunner), configure $app->views(autoReload: false) and run kongo optimize to keep compiled template closures hot in memory with zero filesystem checks. Bind $views->withVite(new ViteManifest($baseDir . '/public')) and drop @vite(['resources/css/app.css', 'resources/js/app.js']) into your layout for Vite dev HMR & hashed production manifests.

5. Kongono Live 2.5 & Bridge (React / Vue / Svelte)

Kongono Live 2.5 (Zero-Build, Strict-CSP Hypermedia)

Add LiveMiddleware and drop @liveScript in your layout for a ~3 KB runtime that requires zero npm build steps and zero unsafe-eval:

  • Keyed DOM Morphing & View Transitions: kgn-get, kgn-post, kgn-target, kgn-swap="morph", and automatic CSRF header forwarding.
  • Zero-eval() Cached-AST Signals: Reactive client state with safe arithmetic, ternary, and pipe expressions under strict Content-Security-Policy.
  • UX Primitives Built In: Speculative hover/visible prefetch, out-of-band multi-target updates (kgn-oob), persistent drafts & offline idempotent queue (k-persist), drag-and-drop ordering (kgn-sortable), optimistic UI, and live SSE streams (kgn-stream).

Kongono Bridge (React, Vue, Svelte & Hybrid Islands)

When a page needs a full JS component tree, scaffold Bridge with kongo bridge:init and generate TypeScript page/DTO definitions via kongo bridge:types. Return Response::page('Orders/Show', $props), embed hybrid islands inside .kgn.html templates with @island('Chart', $props), or serve HTML, Live fragments, Bridge pages, and JSON from a single controller via Response::adaptive().

6. Typed DTO Validation & HTML PRG Flash

Type-hint any readonly DTO in a controller method. Kongono validates JSON or form input, coerces scalars and BackedEnums, validates nested DTOs and typed arrays recursively, and returns 422 Unprocessable Content (or flashes secret-scrubbed @old() / @error() values on HTML PRG redirects).

final readonly class CreateTicketInput implements ValidatableDtoInterface
{
    /** @param list<string> $labels */
    public function __construct(
        #[Required, Uuid] public string $clientRequestId,
        #[Required, Min(3), Max(140)] public string $subject,
        #[Required, Email] public string $reporterEmail,
        #[Between(1, 5)] public int $severity,
        #[Date] public ?string $dueDate = null,
        #[Ip] public ?string $sourceIp = null,
        #[NotIn(['internal'])] public string $category = 'support',
        #[RequiredIf('severity', 5)] public ?string $escalationEmail = null,
        #[ArrayOf('string', min: 1, max: 5)] public array $labels = ['triage'],
    ) {}

    /** @return array<string, string|list<string>> */
    public function validate(): array
    {
        // Custom cross-field validation; custom RuleInterface attributes also supported
        return [];
    }
}

#[ArrayOf] automatically emits accurate array item schemas in OpenAPI 3.1, kongo sdk:generate, and kongo bridge:types.

7. HTTP Caching, Compression, SSE & Idempotency

  • HTTP Caching & 304: Decorate GET handlers with #[CacheControl(maxAge: 300, public: true, staleWhileRevalidate: 60)] for automatic weak ETag and 304 Not Modified handling.
  • Compression: Add new CompressionMiddleware() for automatic gzip/deflate encoding (safely skips streaming SSE & binary payloads).
  • Idempotency: Decorate mutating actions with #[Idempotent(ttlSeconds: 86400)] — retries with the same Idempotency-Key replay cleanly, while payload mismatches fail closed with 409 Conflict.
  • Real-Time SSE Pub/Sub: Publish events across single-node EventBus or multi-node RedisEventBus and stream replays honoring Last-Event-ID via Response::sse(...).

8. Database, Soft Deletes, BatchLoader & Migrations

Every value in QueryBuilder is bound via real PDO prepared statements (ATTR_EMULATE_PREPARES = false) with automatic reconnect and statement caching. Unscoped UPDATE/DELETE statements fail closed by default.

$db = PdoConnection::fromUrl(Config::env('DATABASE_URL'));
$db->onQuery(fn(string $sql, float $ms) => $inspector->recordQuery($sql, $ms));

// Tenant isolation + soft deletes + pagination + zero-N+1 BatchLoader
$page = $db->table('articles')
    ->forTenant($tenant)
    ->withoutTrashed()
    ->orderBy('created_at', 'DESC')
    ->paginate(page: 1, perPage: 20);

$authors = BatchLoader::belongsTo($db, $page->items, 'users', 'author_id');
$comments = BatchLoader::hasMany($db, $page->items, 'comments', 'article_id');

// Soft delete / query trash / restore
$db->table('articles')->where('id', '=', $id)->softDelete();
$trashed = $db->table('articles')->onlyTrashed()->getAs(ArticleDto::class);
$db->table('articles')->where('id', '=', $id)->restore();

Use Schema::create(), Schema::table(), Schema::rename(), and Blueprint helpers (uuid, json, decimal, foreignId, softDeletes), plus PostgreSQL RowLevelSecurity, NonTransactionalMigrationInterface (for CREATE INDEX CONCURRENTLY), QueryGuard for N+1 detection, and typed Factory::for() for seeds and tests.

php vendor/bin/kongo make:migration add_deleted_at_to_articles
php vendor/bin/kongo migrate --pretend      # Dry-run SQL preview without touching DB
php vendor/bin/kongo migrate:lint           # Zero-downtime lock/safety linter
php vendor/bin/kongo migrate
php vendor/bin/kongo migrate:fresh          # Guarded against production (requires --force)

9. Full-Text & Hybrid RRF Search

Combine exact keyword matching (PostgresFullTextSearch using tsvector / websearch_to_tsquery / ts_rank_cd with XSS-safe plain-text [[/]] snippets, or MemorySearchEngine in tests) with semantic vector search (PgVectorStore HNSW/GIN) via Reciprocal Rank Fusion:

use Kongono\Ai\Embedding\{HybridSearch, PgVectorStore};
use Kongono\Database\Search\PostgresFullTextSearch;

$fts = new PostgresFullTextSearch($db, table: 'kb_articles', textColumns: ['title', 'body']);
$vectors = new PgVectorStore($db);

$hybrid = new HybridSearch($fts, $vectors, rrfK: 60, keywordWeight: 1.0, vectorWeight: 1.0);
$hits = $hybrid->search(
    queryText: 'zero-downtime migration lint',
    queryVector: $embedder->embed(['zero-downtime migration lint'])[0],
    limit: 10,
);

10. Auth, PATs, Security & AI Threat Shield

  • Full Auth Stack (Zero Vendor Packages): SessionAuth + SessionAuthMiddleware + #[Authenticated], Gate policies & before() hooks, #[Can('ability')], revocable SHA-256 PersonalAccessToken (Memory/Cache/Pdo stores with automatic kgn_pat_ redaction in SecretScrubber), PasswordResetBroker, EmailVerifier, LoginThrottler, and split selector/validator RememberMeManager (revokes entire series on stolen-cookie detection).
  • Passwordless & MFA: Native WebAuthn/FIDO2 Passkeys (PasskeyVerifier ES256/Ed25519), single-use HMAC MagicLinkAuth, PKCE S256 PkceOAuthClient (GitHub/Google/OIDC), and RFC 6238 Totp + recovery codes.
  • Cryptography & Content Safety: Argon2id PasswordHasher, versioned HKDF Encryptor v2 (XChaCha20-Poly1305 AEAD + seamless key rotation), HTML5 HtmlSanitizer/@safeHtml, HMAC TokenSigner, and expiring SignedUrl.
  • SSRF & AI Attack Defense: DNS-pinned SafeHttpClient (blocks loopback/private/metadata IPs), signed WebhookDispatcher + #[VerifyWebhook], AiThreatShieldMiddleware (recon honeypots, hidden form traps, 404 burst auto-banning, compute budgets), and PromptGuard/UntrustedInput cryptographic Canary Token leakage blocking.

11. Storage, Queues, Batches, Workflows & Mail

  • Streaming Storage: Stream large files with putStream()/getStream() and native copy()/move() across contained atomic LocalStorage, pure-PHP AWS SigV4 S3Storage (paginated ListObjectsV2, native x-amz-copy-source, presigned URLs), and MemoryStorage. Add magic-byte UploadedFileStore, SignedLocalUrl, multi-disk StorageDisks, StorageFactory, and Response::download() / Response::fromStorage().
  • Queues, Priority & Dead-Letter Replay: PostgresQueueDriver (FOR UPDATE SKIP LOCKED + fencing tokens) and pure-PHP Lua-atomic RedisQueueDriver support multi-queue priority draining (Worker::run('critical,high,default')), atomic uniqueKey dedup, composable JobMiddlewareInterface, --daemon workers, and DLQ CLI commands (kongo queue:failed, queue:retry, queue:flush).
  • Parallel Batches & Durable Workflows: Fan-out/fan-in with JobBatch + BatchDispatcher (then/catch/finally callbacks on MemoryBatchStore or CacheBatchStore), or build multi-day durable Workflows with memoized $wf->step(), sleep(), and external waitForEvent()/signal().
  • Pure-PHP Redis & Mail: Zero-extension RedisClient (auto-reconnect, TLS, RESP2/RESP3) powers RedisCache, RedisEventBus, and RedisQueueDriver. Transactional Mailer ships with SmtpTransport (STARTTLS), ResendTransport, .kgn.html views, and NotificationDispatcher.

12. Testing: TestClient, Savepoints, Fakes & Clock

Kongono tests run with zero global mutable state — safe for parallel test runners and persistent workers alike:

// Fluent in-process HTTP, Live 2.5, Bridge & multipart testing
$client = (new TestClient($app))
    ->actingAs($principal)
    ->withStatefulCookies()
    ->followRedirects()
    ->withLive();

$client->postMultipart('/uploads', files: ['doc' => TestUpload::fakePdf('spec.pdf')])
    ->assertCreated()
    ->assertJsonPath('mime', 'application/pdf');

// Fast DB isolation using real transactions + nested SQL SAVEPOINTs
DatabaseTestHelper::inRollbackTransaction($db, function () use ($db): void {
    // Queries and nested $db->transaction() calls roll back cleanly on exit
});

// Pure-DI time travel & SSRF-enforcing outbound HTTP fake
$clock = FrozenClock::at('2026-11-22T09:00:00Z');
$clock->advanceSeconds(3600);
$http = SafeHttpClient::fake(['https://api.example.com/*' => ['status' => 200, 'body' => '{}']]);

13. AI SDK, Evals & 5-Line pgvector RAG

Set any one provider environment variable (OPENAI_API_KEY, ANTHROPIC_API_KEY, GEMINI_API_KEY, GROQ_API_KEY, or OLLAMA_HOST) and use one unified API across all five providers:

$ai = AiClient::fromEnv();

// 1. Live token streaming (OpenAI, Anthropic, Gemini, Groq & Ollama)
$ai->chatStream(
    new ChatRequest([Message::user('Summarize Kongono in 2 bullets')]),
    static function (string $delta): void { echo $delta; },
);

// 2. Validated structured DTO extraction + PromptGuard canary defense
$sentiment = $ai->structured($reviewText, SentimentDto::class);

// 3. 5-Line RAG with PostgreSQL pgvector (HNSW/GIN)
$kb = new KnowledgeBase($embedder, new PgVectorStore($db));
$kb->ingest('docs-1', $markdownText, ['product' => 'kongono']);
$answer = $kb->ask('How does key rotation work?', $ai);

Run php vendor/bin/kongo eval --redteam to execute Kongono's built-in 12-vector adversarial prompt-injection red-team suite and assert structured DTO accuracy, token limits, and latency budgets in CI.

15. Self-Verifying Proofs, Capabilities, Incident Time-Machine & LSP

  • Unified Readiness Certificate (kongo prove): Runs all 5 mathematical proof pillars in one command (A+..F, --json for CI): 17-rule diagnose, policy:check (app/invariants.php), prove:isolation (multi-tenant BOLA/IDOR), perf (persistent-worker leak & SQL N+1 prover), and PHP 8.5 codemod hygiene.
  • Least-Privilege Route Capabilities: Mount CapabilityMiddleware and decorate routes with #[ReadOnlyDb], #[NoOutboundHttp], #[MaxQueries(N)], and #[MaxAiCost(maxUsd: ...)] — enforced pre-execution at PdoConnection and SafeHttpClient.
  • Production Incident Time-Machine ($app->recordIncidents()): Captures secret-scrubbed 5xx failures into storage/incidents/*.json while returning strictly vague KGN-* reference responses when APP_DEBUG=false. Replay locally via kongo incident:replay <ref> and emit permanent PHPUnit 13 regression tests via kongo incident:test <ref>.
  • Change-Safety, Watch Loop & Zero-Dependency LSP: Check blast radius with kongo snapshot / kongo impact --against=..., prove refactor equivalence via kongo shadow:record / kongo shadow:diff --against=..., apply syntax-verified codemods via kongo upgrade --apply --verify, run kongo watch on save, and connect VS Code / Cursor via kongo lsp + editors/vscode-kongono/.

16. /_kongono Dev Studio, /_ops Operations & SDK Generator
