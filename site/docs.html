Kongono v1 Documentation

Everything you need to build, test, and scale modern PHP 8.5+ applications with zero Symfony runtime dependencies.

1. Quick Start

Requirements: PHP 8.5+ (ext-curl, ext-json, ext-mbstring, ext-pdo, ext-sodium) and Composer 2.x.

Create a New Project (Recommended)

composer create-project kongono/app my-app
cd my-app
composer dev

The installer automatically copies .env.example to .env and generates a 256-bit APP_KEY. Open:

  • App Home: http://127.0.0.1:8000/
  • Kongono Dev Studio: http://127.0.0.1:8000/_kongono
  • Interactive OpenAPI 3.1 Explorer: http://127.0.0.1:8000/docs
  • Readiness Health Check: http://127.0.0.1:8000/health

Install into an Existing Project

composer require kongono/framework
php vendor/bin/kongo doctor

3. Routing & PHP 8.5 Attributes

Register controllers with $app->controller(PostController::class) or fluent route closures via $app->routes(fn(Router $r) => ...). Route handlers receive automatic DI for Request, Session, Principal, typed route params (int $id), Container services, and validated DTOs.

#[Prefix('/api/posts')]
final readonly class PostController
{
    #[Get('/', name: 'posts.index')]
    #[CacheControl(maxAge: 60, public: true, staleWhileRevalidate: 30)]
    public function index(): Response { ... }

    #[Get('/{id:\d+}', name: 'posts.show')]
    public function show(int $id): Response { ... }

    #[Post('/', name: 'posts.create')]
    #[Middleware(BearerAuthMiddleware::class)]
    #[Can('posts.write')]
    #[Idempotent(ttlSeconds: 3600)]
    public function store(CreatePostInput $input, Principal $principal): Response { ... }
}
Custom Route Attributes: Any PHP 8.5 attribute implementing Kongono\Http\Routing\MiddlewareAttributeInterface automatically attaches PSR-15 middleware resolved from the Container!

4. Compiled .kgn.html Views & Components

Templates live in views/ and compile once into opcache-friendly PHP files. All {{ $expr }} and @t(...) outputs are contextually HTML-escaped against XSS.

@extends('layouts/app')
@section('title', 'Dashboard')

@section('content')
  <h1>@t('dashboard.welcome', ['name' => $user->name])</h1>

  @unless ($archived)
    <x-card :title="$project->name">
      @forelse ($tasks as $task)
        <p>{{ $task->title }}</p>
      @empty
        <p>All caught up!</p>
      @endforelse
    </x-card>
  @endunless

  <script>window.__DATA__ = @json($payload);</script>
@endsection

Precompile every view before deploying with php vendor/bin/kongo optimize (calls ViewEngine::warmCache()). In production persistent workers (FrankenPHP / RoadRunner), pass $app->views(autoReload: false) (or $views->withAutoReload(false)) to keep compiled template closures hot in memory with zero per-request filesystem checks.

First-Class Vite Integration (@vite)

Bind $views->withVite(new ViteManifest($baseDir . '/public')) and drop @vite(['resources/css/app.css', 'resources/js/app.js']) into your layout. Kongono automatically emits Vite HMR tags when public/hot exists and hashed CSS + modulepreload + module scripts from public/build/manifest.json in production.

5. Typed DTO Validation

Type-hint any readonly DTO in a controller method. Kongono validates JSON or form input, coerces scalars and BackedEnums, validates nested DTOs recursively, and returns a structured 422 Unprocessable Content response with dotted field keys (e.g. shipping.postalCode) on failure.

enum Priority: string { case Low = 'low'; case High = 'high'; }

final readonly class CreateTicketInput
{
    public function __construct(
        #[Required, Uuid] public string $clientRequestId,
        #[Required, Min(3), Max(140)] public string $subject,
        #[Required, Email] public string $reporterEmail,
        #[Between(1, 5)] public int $severity,
        public Priority $priority = Priority::Low,
    ) {}
}

Built-in attributes: #[Required], #[Min], #[Max], #[Between], #[Email], #[Url], #[Uuid], #[In], #[Regex], and #[Confirmed('password')].

6. Caching, Compression, SSE & Idempotency

  • HTTP Caching & 304: Decorate GET handlers with #[CacheControl(maxAge: 300, public: true, staleWhileRevalidate: 60)] to emit Cache-Control, weak ETag, and automatic 304 Not Modified responses.
  • Compression: Add new CompressionMiddleware() for automatic gzip/deflate encoding (safely skips streaming SSE & binary payloads).
  • Idempotency: Decorate mutating actions with #[Idempotent(ttlSeconds: 86400)] — retries with the same Idempotency-Key replay cleanly (Idempotency-Replayed: true), while payload mismatches fail closed with 409 Conflict.
  • Real-Time SSE Pub/Sub: Publish events with $eventBus->publish('notes', 'note.created', $data) and stream replays honoring Last-Event-ID via Response::sse(...).

7. Database, Migrations & Seeders

Every value in QueryBuilder is bound via real PDO prepared statements (ATTR_EMULATE_PREPARES = false). Unscoped UPDATE/DELETE statements fail closed by default.

$db = PdoConnection::fromUrl(Config::env('DATABASE_URL'));
$db->onQuery(fn(string $sql, float $ms) => $inspector->recordQuery($sql, $ms));

$page = $db->table('articles')
    ->leftJoin('users', 'users.id', '=', 'articles.author_id')
    ->where('articles.published', '=', true)
    ->whereGroup(fn(QueryBuilder $q) => $q->where('featured', '=', true)->orWhere('views', '>=', 1000))
    ->orderBy('articles.created_at', 'DESC')
    ->paginate(page: 1, perPage: 20);

// Hydrate directly into readonly DTOs (snake_case -> camelCase)
$dtos = $db->table('articles')->limit(10)->getAs(ArticleDto::class);
php vendor/bin/kongo make:migration create_articles
php vendor/bin/kongo migrate
php vendor/bin/kongo migrate:rollback --steps=1
php vendor/bin/kongo make:seeder Articles
php vendor/bin/kongo db:seed

8. Security, TOTP 2FA & Signed Webhooks

  • Principals & Authorization: Typed Principal (Human, Service, Agent, System), fail-closed Gate, and declarative #[Can('ability')] route attributes.
  • Cryptography: Argon2id PasswordHasher, AEAD XChaCha20-Poly1305 Encryptor with previousKeys rotation, HMAC TokenSigner, and expiring SignedUrl.
  • RFC 6238 TOTP 2FA: Totp::generateSecret(), $totp->provisioningUri(...), $totp->verify($secret, $code), and Totp::generateRecoveryCodes().
  • SSRF-Hardened Egress & Webhooks: SafeHttpClient pins resolved public IPs via CURLOPT_RESOLVE and blocks loopback/private/cloud-metadata IPs. Pair with WebhookDispatcher outbound and #[VerifyWebhook] inbound.

9. Storage, Queues, Redis & Mail

  • Storage: Root-contained atomic LocalStorage (SHA-256 versioned + optimistic concurrency) and zero-dependency AWS SigV4 S3Storage (works with AWS S3, Cloudflare R2, and MinIO, including presigned URLs).
  • Pure-PHP Redis / Valkey: RedisClient::fromUrl('redis://127.0.0.1:6379/0') powers RedisCache (drop-in for sessions, rate limits, feature flags, and idempotency) and RedisQueueDriver with zero ext-redis compilation.
  • Queues & Cron Scheduler: PostgresQueueDriver (FOR UPDATE SKIP LOCKED + fencing tokens), RedisQueueDriver, Worker preserving JobOutcome::Uncertain, and fluent cron Scheduler (kongo work / kongo schedule:run).
  • Mail & Notifications: Mailer (SmtpTransport STARTTLS, ResendTransport, compiled .kgn.html email views) + multi-channel NotificationDispatcher (MailNotificationChannel, WebhookNotificationChannel, MemoryNotificationChannel).

10. AI SDK, Streaming & 5-Line pgvector RAG

Set any one provider environment variable (OPENAI_API_KEY, ANTHROPIC_API_KEY, GEMINI_API_KEY, or OLLAMA_HOST) and use one unified API across all four providers:

$ai = AiClient::fromEnv();

// 1. Live token streaming (OpenAI, Anthropic, Gemini & Ollama)
$ai->chatStream(
    new ChatRequest([Message::user('Summarize Kongono in 2 bullets')]),
    static function (string $delta): void { echo $delta; },
);

// 2. Validated structured DTO extraction
$sentiment = $ai->structured($reviewText, SentimentDto::class);

// 3. 5-Line RAG with PostgreSQL pgvector
$kb = new KnowledgeBase($embedder, new PgVectorStore($db));
$kb->ingest('docs-1', $markdownText, ['product' => 'kongono']);
$answer = $kb->ask('How does key rotation work?', $ai);

11. Built-In AI Companions & Native MCP Server

Every Kongono app ships with three built-in AI companions plus a capability-governed JSON-RPC 2.0 MCP server:

php vendor/bin/kongo oshie --interactive            # Learn Kongono interactively
php vendor/bin/kongo chie "Add a /api/posts CRUD"   # Diff preview (--apply to write)
php vendor/bin/kongo hantei check                   # Run tests & AI-diagnose failures
php vendor/bin/kongo mcp                            # Start stdio MCP server

Connect Antigravity, Cursor, Claude Code, or Codex via MCP

{
  "mcpServers": {
    "kongono": {
      "command": "php",
      "args": ["vendor/bin/kongo", "mcp"]
    }
  }
}

Exposed read-only, secret-scrubbed MCP tools (.env reads explicitly blocked): kongono_graph, kongono_openapi, kongono_routes, kongono_list_files, kongono_read_file, and kongono_oshie_lesson.

12. Dev Studio, Feature Flags & Resilience

  • Kongono Dev Studio (/_kongono): Live request/SQL trace viewer, route explorer, ApplicationGraph service & middleware inspector, and interactive browser Oshie, Chie (diff preview), Hantei & MCP studio. Automatically returns 404 when APP_DEBUG=false.
  • Feature Flags: $features->rollout('new_ui', 25) for deterministic percentage rollouts + #[Feature('new_ui')] route gating.
  • Resilience: Retry::run($fn, maxAttempts: 3, baseDelayMs: 100) and CircuitBreaker (Closed → Open → HalfOpen) protect upstream API calls.
  • Observability: GET /health readiness JSON, GET /metrics Prometheus exposition, and Server-Timing headers via Tracer.

13. Production Deployment (FrankenPHP)

Apps created with kongono/app ship with a production FrankenPHP persistent-worker Dockerfile, Caddyfile, and public/worker.php:

docker build -t my-kongono-app .
docker run -p 8080:8080 --env-file .env.production my-kongono-app

Key checklist: set APP_DEBUG=false, run php vendor/bin/kongo optimize during image build, rotate APP_KEY with Encryptor::$previousKeys, and point load-balancer probes to /health.
