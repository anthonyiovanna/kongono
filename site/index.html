declare(strict_types=1);

use Kongono\Http\Response;

use Kongono\Security\Attributes\Can;
use Kongono\Security\Middleware\BearerAuthMiddleware;
use Kongono\Security\Principal;

#[Prefix('/api/notes')]
final readonly class NoteController
{
    #[Get('/', name: 'notes.index')]
    #[CacheControl(maxAge: 60, public: true, staleWhileRevalidate: 30)]
    public function index(): Response { /* auto ETag & 304 Not Modified */ }

    #[Post('/', name: 'notes.create')]
    #[Middleware(BearerAuthMiddleware::class)]
    #[Can('notes.write')]
    #[Idempotent(ttlSeconds: 3600)]
    public function create(CreateNoteInput $input, Principal $actor): Response
    {
        return Response::json(['author' => $actor->id, 'title' => $input->title], 201);
    }

    #[Get('/insights', name: 'notes.insights')]
    #[Feature('beta_insights')]
    public function insights(): Response { /* fail-closed 404 unless enabled */ }
}

Three Built-In AI Companions + Native MCP Server

Works with OpenAI, Anthropic Claude, Google Gemini, or free local Ollama — grounded directly in your app's live ApplicationGraph with automatic secret scrubbing.

Oshie (教え) · Learn

Interactive AI Tutor

Built-in lessons + multi-turn CLI REPL (kongo oshie --interactive) and browser AI Studio inside /_kongono that teaches Kongono using your actual routes and services.

Chie (知恵) · Build

Project-Aware AI Builder

Runs under a capability-governed AgentPrincipal, reads your live project structure, renders unified diffs first, and writes strictly contained PHP 8.5 code only when you pass --apply.

Hantei (判定) · Debug & Test

AI Debugger & Test Generator

Runs PHPUnit, scrubs secrets via SecretScrubber, diagnoses failures against your live app graph (CLI & browser), and generates PHPUnit 13 tests.

MCP · JSON-RPC 2.0

Native Model Context Protocol

Run php vendor/bin/kongo mcp (stdio) or POST /mcp so Antigravity, Cursor, Claude Code, and Codex inspect your live routes, graph, and OpenAPI 3.1 spec safely.

/_kongono & /docs

Zero-CDN Dev Studio & API Explorer

Built-in dark-mode request/SQL inspector, service graph viewer, Oshie/Hantei browser workbench, and interactive OpenAPI 3.1 Explorer — fail-closed in production.
